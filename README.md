## ⚡ Tech Stack & Architecture

- **Core**: React 18, ESNext JavaScript, Vite 6
- **Styling**: Tailored **Vanilla CSS Design System** (Warm Editorial `#F7F5F0` default with togglable Dark Technical `#0D0E10` mode, fluid typographic scale, restrained micro-interactions)
- **Typography**: Space Grotesk (Headings), Inter (Body), JetBrains Mono (Technical indices & tags)
- **Icons**: Lucide React
- **Flagship Spotlight**: **Shiro.ai** — Psychometric Mastery Modeling (Item Response Theory & Bayesian Knowledge Tracing) coupled with Hybrid Dense+Sparse RAG (ChromaDB + BM25) and automated RAG Triad observability.
- **Mobile-First**: Fully responsive across mobile viewports (320px–430px), tablets, and desktop.

## 🚀 Local Development Setup

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Vite Dev Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Production Build
```bash
npm run build
```
